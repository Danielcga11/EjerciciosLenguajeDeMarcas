Definiciones html

  • HTML: lenguaje utilizado para crear y estructurar páginas web.
  • Etiqueta: elemento de HTML que indica cómo debe organizarse o mostrarse un contenido.
  • Atributo: información adicional que modifica o describe una etiqueta.
  • Elemento: conjunto formado normalmente por una etiqueta de apertura, el contenido y una etiqueta de cierre.
  • Navegador: programa que permite visualizar páginas web, como Chrome o Firefox.
  • URL: dirección que identifica una página o recurso en Internet.
