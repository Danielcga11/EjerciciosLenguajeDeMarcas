¿Que es WWW (World Wide Web)?

La WWW es un sistema que permite acceder a información a través de Internet. Para crear páginas web se utiliza HTML un lenguaje que organiza el contenido mediante etiquetas. También son importantes URL , que identifica las direcciones web, y HTTP, que permite la comunicación entre el navegador y el servidor. Gracias a estas tecnologías podemos navegar y consultar páginas en Internet.
